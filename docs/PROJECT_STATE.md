5. **Transport + admin cross-cutting** — an HTTP/GraphQL + gRPC transport (so the admin UI and storefront call the contexts/`apps/admin` facades); the admin baseline (tracking, audit-on-mutation `audit.entry.recorded`, RBAC/ReBAC via Ory/Keto, feature-flag gating, bulk-action jobs).
